# Projeto calculadora  em C

**Fernanda Lima Pessanha**

 Apresento uma calculadora programada em C com 20 opções de operação. O projeto é uma atividade didática para aprimorar e pôr em práticas conhecimentos básicos de variável com entrada de dados ou atribuições; tipos de dados, int para inteiro, float e double para decimais mudando apenas a capacidade de armazenamento, um pra menos, outro para mais; char para caractectere; entrada e saída de dados, a função printf para exibir mensagens e pedir valores, a função scanf para armazenar informações atreladas a variáveis e fazer a leitura, concatenação da função printf para unir valor de variável com texto, estruturas de condicionais if, else, else e switch-case. Foi escolhida a condicional de if, else e else elif no programa desenvolvida, onde quando verdadeira é realizada uma operação e quando falsa recorrendo ao uso de elif else, um novo bloco é criado até que se chegue a uma verdadeira realizando cálculos diferentes de acordo com cada alternativa até chegar em else, quando nenhum dos valores anteriores forem atendidos. O laço de repetição é o do while, que executa todo o programa pelo menos uma vez para que possa ser repetido mais alguma vez, isso ajuda a repetir vários cálculos até se optar pela opção de "exit", sair da calculadora e fechar o programa. Como uma calculadora foram utilizados símbolos de operações básicas nas atribuições, como soma, subtração, multiplicação e divisão, enquanto que para realizar algumas funções foi necessário estar a utilizar a biblioteca math para realizar cálculos diretos e práticos e outras, apenas fragmentos de variáveis utilizando operadores básicos imitando as fórmulas dentro de várias variáveis. Dentro das bibliotecas foi utilizada também a stdio.h, uma biblioteca utilizada especificamente para entrada e saída de dados do usuário, com inserção de dados onde o mesmo recebe informações a cerca do que foi enviado à máquina. O objetivo principal dessa calculadora é tornar interativo e acessível um programa com funções de calculadora e além disso, a resolução até mesmo de áreas de figuras geométricas planas que é um diferencial em relação a calculadora científica que torna prático e fácil esses cálculos apenas com algumas informações sobre suas formas e lados para se chegar a um resultado preciso e eficiente que poupa bastante tempo em vez de fazer de forma prática utilizando apenas um lápis e papel. As operações realizadas pela calculadora vão desde operações básicas até trigonometria e logaritmo, msostrando como é interessante ter uma ampla variedade de opções de cálculos tanto para coisas comuns do dia a dia quanto para estudantes mais avançado que quer algo além de operações básicas. O código é executado na opção de execução onde o mesmo é compilado e logo em seguida, é demonstrado um menu com todas as opções disponíveis, tudo o que você deve fazer é escolher a operação desejada, informar os valores necessários, como o lado de um quadrado e aguardar pelo resultado.
