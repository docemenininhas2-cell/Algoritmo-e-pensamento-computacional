# Calculadora no flowgorithm


**Fernanda Lima Pessannha**

O objetivo desse programa é a utilização de um programa com funções de calculadora gerado para realizar cálculos simples de forma prática e acessível.

O funcionamento ocorre com a disposição de opções a partir de uma variável chamada "opções" seguida de um texto como saída que apresenta todas as opções enumeradas onde você ´pode escolher a partir da entrada de dados. As condições são entrelaçadas em verdadeiro e falso e são enumeradas dentro de um bloco estando associado a mesma variável, o número de opções. Dentro de cada condição, quando verdadeira, você fornece como  entrada de dados os valores a serem utilizadas no cálculo , que são armazenados e logo depois usados numa atribuição em que há variáveis dispostas em cada opção, uma variável para inserir cada valor desejado. Logo haverá a fórmula ou função que realiza o cálculo dentro de uma atribuição com uma saída de texto no final informando o resultado.

As operações da calculadora são operações básicas e avançadas comuns de uma calculadora científica, em que todas coletam informações, números a qual se deseja chegar gerando um resultado que se deseja e recebendo em forma de texto um resulltado de acordo.

As instruções básicas é selecionar a opção desejada, inserir os valores e aguardar o resultado.

A calculadora apresenta um cálculo de índice de massa corporal "IMC" e área para as formas geométricas: Quadrado, retângulo, triângulo, cículo, trapézio, losango e paralelogramo dentro das opções da calculadora.
